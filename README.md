# EEG-Based Depth-of-Anesthesia Detection

## Project Overview
This project explores the use of EEG signals and machine learning to estimate the depth of general anesthesia.

## Objectives
- Understand EEG signal preprocessing.
- Explore machine learning and deep learning models.
- Evaluate model performance using appropriate metrics.

## Tools
- Python
- Jupyter Notebook
- NumPy and Pandas
- Scikit-learn
- PyTorch (if required by the selected model)

## Dataset
The dataset will be selected from a publicly accessible research source, subject to its access conditions.

## Current Status
Project setup and literature review.
